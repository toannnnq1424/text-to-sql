# 14 ảnh UI tham chiếu của người dùng

Người dùng cho phép đưa thư mục ảnh này lên GitHub trong yêu cầu ngày 2026-10-19. File PNG giữ nguyên nội dung, chỉ đổi tên ASCII có thứ tự để link ổn định. [manifest.json](manifest.json) lưu tên gốc và SHA-256 để đối chiếu. Không có ảnh AI-generated bổ sung ở bước chuẩn bị.

Mapping đầy đủ ở [docs/ui-reference.md](../docs/ui-reference.md). 01–10 là nguồn canonical cho shell/màn tương ứng; 11–14 bổ sung selector, result summary và metric detail. Không dùng mọi biến thể cùng lúc và không lấy số liệu trong ảnh làm nguồn dữ liệu sản phẩm.
